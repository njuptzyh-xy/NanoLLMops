# NanoLLMOps 文档索引

更新时间：2026-06-02

## 开发前阅读顺序

Codex 每次开始开发前，默认按以下顺序读取文档：

1. `AGENTS.md`
2. `nanoLLMops产品文档.md`
3. `docs/开发规划.md`
4. 当前任务关联的技术文档、阶段总结和运行说明

## 文档职责

| 文档 | 职责 |
| --- | --- |
| `AGENTS.md` | 约束 Codex 的开发、验证、日志、提交和推送行为 |
| `nanoLLMops产品文档.md` | 说明项目业务目标和产品方向 |
| `docs/开发规划.md` | 定义任务编号、当前任务、状态和日志链接 |
| `docs/logs/` | 存放每个开发任务的详细日志 |
| `docs/MVP端到端运行说明.md` | 维护当前可执行命令和验证路径 |
| `docs/phase-*.md` | 记录阶段性总结，不承担日常流水日志职责 |

## 开发日志命名

开发日志统一存放在 `docs/logs/`：

```text
TASK-任务编号_YYYY-MM-DD-HHmm_任务名称.md
```

示例：

```text
TASK-P2-001_2026-06-02-2003_nano-vllm原生接入点调研.md
```

同一任务跨多日开发时，按日期新增日志文件，不覆盖既有日志。
