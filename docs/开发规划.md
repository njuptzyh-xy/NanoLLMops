# NanoLLMOps 开发规划

更新时间：2026-06-02

## 使用说明

本文件是 Codex 领取开发任务的唯一规划入口，只维护任务定义、状态和日志链接。

- 开发前：先阅读 `AGENTS.md`、`docs/文档索引.md` 和本文件。
- 开发中：围绕一个任务编号完成代码、测试和文档改动。
- 开发后：只更新任务状态和日志链接，详细过程写入 `docs/logs/`。
- 日志命名：`TASK-任务编号_YYYY-MM-DD-HHmm_任务名称.md`。

任务状态：

- `TODO`：尚未开始
- `IN_PROGRESS`：正在开发
- `DONE`：已经完成并验证
- `BLOCKED`：存在明确阻塞，需要在日志中说明原因
