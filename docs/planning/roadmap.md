# NanoLLMOps 路线图

更新时间：2026-06-02

## 项目方向

NanoLLMOps 以 `nanoGPT` 为训练侧参考，以 `nano-vllm` 为推理侧参考，逐步形成可验证、可复用的轻量级训推一体化平台。

## 阶段规划

| 阶段 | 状态 | 目标 | 关键任务 |
| --- | --- | --- | --- |
| `PHASE-00` | `DONE` | 建立项目骨架、约束和产物规范 | `P0-001` |
| `PHASE-01` | `DONE` | 打通训练、转换、校验、推理和 CPU runtime 闭环 | `P1-001` 至 `P1-005` |
| `PHASE-02` | `IN_PROGRESS` | 接入正式 `nano-vllm` 路径并补充最小平台能力 | `P2-001` 至 `P2-005` |
| `PHASE-03` | `TODO` | 建立性能指标和回归报告 | `P3-001` |

## 当前重点

当前只推进 `P2-001`：调研正式 `nano-vllm` 原生接入点。

在 `P2-001` 输出适配设计前，不开始原生后端实现。
